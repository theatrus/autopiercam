AutoPierCam for N.I.N.A.
========================

Requires N.I.N.A. 3.2 or newer and the AutoPierCam tray application.

Manual installation
-------------------
1. Close N.I.N.A.
2. Put all files from this archive in:
   %LOCALAPPDATA%\NINA\Plugins\3.0.0\AutoPierCam
3. Start AutoPierCam, then start N.I.N.A.
4. Open Imaging and select the "Pier Camera" dockable panel if needed.

The panel needs no configuration. It reads the protected local AutoPierCam
preview stream and never opens or controls the ZWO camera itself. It reconnects
automatically and retains the last good snapshot, dimmed and labeled stale,
while AutoPierCam is unavailable.
