AutoPierCam 0.2.25 adds a separate settings window and clock-aligned Chatstronomy
image scheduling. It retains Regain 0.5.11.0 and the post-slew selection from
0.2.24, including useful motion images and no exposure cancellation.

## Changes

- Settings opens its own window without replacing the live preview. Imaging and
  Chatstronomy retain their drafts when you switch tabs, with one **Save all
  settings** and **Discard all changes** footer.
- Numeric edits enable Save while you type; you do not need to leave the field.
  Invalid numbers remain visible for correction. Closing settings or the Viewer
  with edits prompts to save both tabs, discard, or keep editing.
- Both drafts are validated before either is written. A later write failure is
  reported explicitly; the two agent requests are not an atomic transaction.
  Successfully saved changes are not written again when retrying the other tab.
- **Send an image every N minutes** uses UTC slots anchored at the Unix epoch,
  not a countdown from Save or connection time. For 15 minutes, slots are
  :00, :15, :30 and :45. Unchanged saves and reconnects preserve the next slot;
  changing N selects the next boundary of the new interval. Zero disables it.
  This is a clock-aligned interval, not a full cron-expression editor.
- Missed slots coalesce instead of forming a backlog. Sharing still needs local
  consent, a connection and a fresh completed preview; a busy event burst may
  take the slot. Post-slew completion wins a coincident periodic slot and keeps
  its conservative timing estimate and send-spacing requirements.

## Validation

Deterministic clock tests cover exact boundaries, repeated configuration,
connection recreation, interval changes, backwards time, missed slots and
periodic/post-slew overlap. A countdown-reset negative control must fail the
clock regression. The settings UI is checked against isolated in-memory agent
responses, with no physical cameras, installed settings writes or live messages.

## Install or upgrade

Use **AutoPierCam-0.2.25-x64.msi**. Existing settings and images are preserved.
Update both the Viewer and agent to get the UI and scheduling changes.
NINA plugin **0.2.25.0** is distributed through both public plugin feeds:
`https://nina-plugins.psf-guard.com/` and `https://nina-plugins.pulsarfab.com/`.
Minimum NINA remains **3.2.0.9001**. The plugin never opens a camera handle.
