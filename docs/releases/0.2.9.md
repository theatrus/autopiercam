AutoPierCam 0.2.9 adds control over minimum gain and the gain/exposure tradeoff.

- **Minimum gain.** Application-controlled exposure can now honor a gain floor.
  Use minimum 200 / maximum 300, or set both to 200 for fixed gain with automatic
  exposure. An unattainable minimum fails explicitly instead of silently using
  a lower gain.
- **Prefer shorter exposures.** This option raises gain before lengthening dark
  exposures, trading noise for cadence. It also rebalances an already converged
  exposure using subsequent frame feedback. Bright frames shorten exposure
  first, and gain never drops below your configured floor.
- **Live updates.** These settings apply on the camera thread without reopening
  the camera or restarting settling. An in-flight exposure may still need to
  finish. The preview frame-rate setting remains a cap, not a guaranteed rate.

After upgrading, open **Settings → Capture**, enable **Application-controlled
day/night exposure**, set **Minimum gain** to 200 and **Max gain** to 300, then
enable **Prefer shorter exposures** and save. Existing configurations retain
minimum 0 and exposure-first behavior until changed. SDK auto has no gain-floor
control; these new options require application-controlled mode.

The deterministic controller and configuration tests pass, but optical day/night
convergence still needs hardware validation. This release does not establish or
claim to fix the reported SDK-auto black-frame root cause. If even minimum
exposure clips at your chosen gain floor, lower the floor.

Install the signed **AutoPierCam-0.2.9-x64.msi** to update the agent and Viewer.
Configuration, captures and pairing credentials are retained. Upgrading does
not enable image sharing. The MSI and application payloads are signed as
**StackFoundry LLC**. ZWO camera drivers and optional FFmpeg remain separate.

The signed NINA plugin **0.2.9.0** is published to the shared registry at
`https://nina-plugins.psf-guard.com/` and `https://nina-plugins.pulsarfab.com/`.
It requires NINA **3.2.0.9001+** and the separately installed AutoPierCam agent
on the same PC and Windows account. Plugin behavior is unchanged.
