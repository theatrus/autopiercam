AutoPierCam's first Windows release: unattended ZWO ASI pier-camera capture,
a system-tray agent, WinUI Viewer, and a read-only N.I.N.A. Imaging-tab panel.

## Downloads

- **AutoPierCam-0.1.0-x64.msi**: install the capture agent and Viewer for your
  Windows account. Install the ZWO Windows camera driver separately.
- **AutoPierCam.NINA.0.1.0.0.zip**: with N.I.N.A. closed, extract into
  `%LOCALAPPDATA%\NINA\Plugins\3.0.0\AutoPierCam`. Requires N.I.N.A. 3.2 or newer.
- The N.I.N.A. manifest and **SHA256SUMS.txt** accompany these downloads.

First-party Windows binaries, the N.I.N.A. DLL, and the MSI are Authenticode
signed as **StackFoundry LLC**. Source is licensed Apache-2.0; author: Yann Ramin.

## Included

- Full-resolution RAW8 acquisition, debayered JPEG stills, and live previews.
- SDK automatic exposure up to the camera's supported ceiling: 60 seconds on
  the tested ASI676MC. Existing saved limits remain unchanged after upgrading.
- Startup previews, exposure-aware freshness, bounded cancellation and camera
  stall recovery, and automatic reconnect.
- Durable HTTP uploads, retry/outbox management, and safe capture retention.
- Optional start at sign-in. Settings, captures, logs, and upload history are
  retained when upgrading or uninstalling.

## Known limitations

The ASI676MC has been hardware-tested, including manual 30/60-second exposures.
ASI662MC hardware coverage and a real dark-to-bright optical transition still
need validation. This release uses SDK auto exposure; custom control beyond
60 seconds, RAW16 night stills, and compressed video are not included. The
agent runs in your signed-in desktop session, not as a Windows service.

See the [installation guide](https://github.com/theatrus/autopiercam/blob/v0.1.0/docs/installation.md)
and [exposure guide](https://github.com/theatrus/autopiercam/blob/v0.1.0/docs/exposure.md).
