AutoPierCam 0.2.6 matches the Chatstronomy Hub's new one-image-per-minute limit.

- The Chatstronomy Hub now posts at most one image per camera per minute. It
  answers an image that arrives too soon with `elided` and later posts a notice
  with the number of skipped images. AutoPierCam now shows this as
  "Connected; image skipped (the Hub posts at most one per minute)" instead of
  "Hub declined the image".
- A skipped image is dropped, not retried. The scene reference stays in place,
  so a lasting scene change is sent once the minute has passed.

Earlier versions already drop `elided` images correctly and only show the older
status text, so this update is optional.

Install the signed **AutoPierCam-0.2.6-x64.msi** to update the agent and Viewer.
Configuration, captures and pairing credentials are retained. Upgrading does
not enable image sharing. The MSI and application payloads are signed as
**StackFoundry LLC**. ZWO camera drivers and optional FFmpeg remain separate.

The signed NINA plugin **0.2.6.0** is published to the shared registry at
`https://nina-plugins.psf-guard.com/` and `https://nina-plugins.pulsarfab.com/`.
It requires NINA **3.2.0.9001+** and the separately installed AutoPierCam agent
on the same PC and Windows account.
