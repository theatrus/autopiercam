AutoPierCam 0.2.12 moves capture to supervised Regain camera drivers.

- ZWO SDK remains the default backend, including for ASI662MC. Camera calls run in a separate worker with bounded deadlines.
- ASI676MC supports experimental Direct USB with exposures up to 2,000 seconds. Select the driver explicitly in Settings; there is no automatic fallback.
- Both backends use application-controlled exposure and gain, preserving configured limits and the shorter-exposure preference. Individual exposures follow the preview/still schedule; discovery never runs while acquiring.
- Driver faults require an operator restart or settings save. AutoPierCam does not reset USB or repeatedly reopen a faulted camera.
- Optional experimental sky labels run locally in a separate Rust CPU worker. Enable them in the Viewer's model settings with your own ONNX model and model JSON. No model ships with this release, and predictions never trigger alerts, sharing or camera actions.
- Adds offline training and prediction-parity tools. Private captures, dataset locations and model weights are not bundled.

Physical ASI676MC tests passed at 1, 30 and 60 seconds through the SDK, and
60, 120 and 2,000 seconds through Direct USB. The longest full-frame RAW16
integration took 2,000.190 seconds, with no SDK loaded, no read retries and
byte-identical retained-frame replay. Both backends saved full-resolution
16-bit PNGs; cancellation and subsequent capture were also tested. These checks
do not establish sky-model accuracy, day/night convergence or USB fault recovery.
ASI662MC Direct USB is not supported yet.

Install **AutoPierCam-0.2.12-x64.msi** to update the agent and Viewer. Settings,
captures and pairing credentials are retained. Older SDK-auto configurations now
use application control without discarding their exposure/gain limits. The
installer and first-party payloads are signed by **StackFoundry LLC**. ZWO
hardware drivers and optional FFmpeg remain separate installations.

NINA plugin **0.2.12.0** is published through both shared registries:
`https://nina-plugins.psf-guard.com/` and `https://nina-plugins.pulsarfab.com/`.
It requires NINA **3.2.0.9001+** and the AutoPierCam agent on the same PC and
Windows account. Plugin behavior is unchanged.
