AutoPierCam 0.2.7 hardens camera operation and brings Capture and Chatstronomy
settings into one consistent panel.

- **No live SDK camera rescans.** Camera discovery happens before capture opens
  the camera. Reload camera list reads the cached inventory during acquisition,
  avoiding an SDK path implicated in a capture hang.
- **Truthful stall status and bounded quit.** A nonresponsive capture worker is
  detected independently of Viewer polling. Restart retains the old camera
  owner until it exits; it never opens competing handles. Quit has a 30-second
  process-exit fallback if native SDK cleanup hangs. Unfinished artifacts can be
  interrupted by that fallback.
- **Configurable preview rate.** Settings → Capture now offers 1–30 fps, default
  2. Short exposures are paced by stopping/restarting the video stream on the
  existing handle. Long exposures are not interrupted. Faster scheduled stills
  and Save next frame can acquire sooner without increasing the preview cap.
  Changing only this setting does not reopen the camera or repeat settling.
- **Unified Settings.** Capture and Chatstronomy use matching Reload, Discard,
  Save and conflict-review controls. Draft edits survive switching sections or
  hiding the panel, and pairing stays within Settings → Chatstronomy.

This is a recommended update for SDK capture hangs. It does not repair a wedged
USB device/driver or automatically terminate a stuck SDK thread and reopen it.
The runtime still uses the ZWO SDK; a Regain backend is not included. New stream
pacing has automated timing coverage but still needs a target-camera day/night
soak test, particularly SDK auto-exposure convergence and sustained stop/start.

Install the signed **AutoPierCam-0.2.7-x64.msi** to update the agent and Viewer.
Configuration, captures and pairing credentials are retained. Upgrading does
not enable image sharing. The MSI and application payloads are signed as
**StackFoundry LLC**. ZWO camera drivers and optional FFmpeg remain separate.

The signed NINA plugin **0.2.7.0** is published to the shared registry at
`https://nina-plugins.psf-guard.com/` and `https://nina-plugins.pulsarfab.com/`.
It requires NINA **3.2.0.9001+** and the separately installed AutoPierCam agent
on the same PC and Windows account.
