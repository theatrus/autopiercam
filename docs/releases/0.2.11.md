AutoPierCam 0.2.11 reduces false Chatstronomy scene-change posts during exposure adjustments.

- Compensates for global brightness, contrast, and black-level changes before comparing images.
- Triggers from one completed frame; no frame averaging or confirmation exposures.
- Filters isolated noise using neighboring image cells.
- Skips unreliable dark/clipped images without replacing the reference.
- Keeps the last scene-change image delivered to chat as the reference, so slow drift still accumulates.

The change percentage still controls how much of the image must change. Local
lighting changes and moving shadows can still trigger; this is not object recognition.
Existing sharing settings and permissions are unchanged. Tests use synthetic
images; no physical camera or live chat was used for validation.

Install **AutoPierCam-0.2.11-x64.msi** to update the agent and Viewer.
Settings, captures, and pairing credentials are retained. The installer and
application payloads are signed by **StackFoundry LLC**. ZWO drivers and optional
FFmpeg are installed separately.

NINA plugin **0.2.11.0** is published through both shared registries:
`https://nina-plugins.psf-guard.com/` and `https://nina-plugins.pulsarfab.com/`.
It requires NINA **3.2.0.9001+** and the AutoPierCam agent on the same PC and
Windows account. Plugin behavior is unchanged.
