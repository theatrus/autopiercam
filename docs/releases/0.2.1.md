AutoPierCam 0.2.1 fixes camera selection when multiple ZWO ASI cameras are attached.

- The Viewer now lists detected color cameras by model and SDK camera ID, even
  when capture faults because more than one camera matches.
- Choose a camera and Save settings to restart capture. Refresh cameras preserves
  other unsaved settings, and a disconnected saved camera is not silently replaced.
- Camera discovery runs on the capture thread without opening extra camera handles.
- Added Pause/Resume recording to the Viewer; preview remains live while scheduled
  stills, security video and sharing are paused.
- Added headless Viewer selection/control-protocol regression tests.
- NINA plugin releases are published to the shared theatr.us registry, with automated
  identity, version and ZIP-checksum validation.

Download **AutoPierCam-0.2.1-x64.msi** for the signed per-user Windows installer.
Existing capture/sharing settings are retained. The MSI and application payloads
are signed as **StackFoundry LLC**. Install the ZWO camera driver separately.

For NINA, add `https://nina-plugins.psf-guard.com/` (or its alias
`https://nina-plugins.pulsarfab.com/`) as a plugin repository and install AutoPierCam.
The standalone archive is **AutoPierCam.NINA.0.2.1.0.zip**; requires NINA 3.2.0.9001+.
The plugin requires the separately installed agent and never opens the camera.

Camera IDs can change after USB reconnects. Recheck the selection after reconnecting;
serial-number binding for identical models and browsing historical artifacts remain
future work. No camera settings or live sharing permissions are changed automatically.
