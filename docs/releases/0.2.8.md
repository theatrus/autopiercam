AutoPierCam 0.2.8 fixes saving settings and improves the Viewer settings layout.

- **Save works when changes are pending.** A missing optional Chatstronomy
  status poll no longer falsely marks the capture agent disconnected and
  disables Save. Actual agent connection failures still disable capture actions.
- **Settings fit the window.** Each section has one width-constrained scrolling
  form with room for its scrollbar. Save and Discard stay visible; the camera
  picker scrolls with the form and discovery details open on demand.
- **Better high-DPI layout.** The initial window respects display scaling and
  the monitor work area. Settings uses the full workspace in narrow windows,
  and long numeric fields stack vertically instead of clipping.

This is a recommended update for users of the 0.2.7 unified Settings panel.
Camera capture behavior is unchanged from 0.2.7, including its SDK hardening
and configurable preview-rate limit.

Install the signed **AutoPierCam-0.2.8-x64.msi** to update the agent and Viewer.
Configuration, captures and pairing credentials are retained. Upgrading does
not enable image sharing. The MSI and application payloads are signed as
**StackFoundry LLC**. ZWO camera drivers and optional FFmpeg remain separate.

The signed NINA plugin **0.2.8.0** is published to the shared registry at
`https://nina-plugins.psf-guard.com/` and `https://nina-plugins.pulsarfab.com/`.
It requires NINA **3.2.0.9001+** and the separately installed AutoPierCam agent
on the same PC and Windows account. This release does not change plugin behavior.
