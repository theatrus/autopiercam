AutoPierCam 0.2.24 improves Chatstronomy slew-image captions and post-slew
selection, using the Regain 0.5.11.0 maintenance release.

## Changes

- Motion images remain useful: start updates and numbered follow-ups may show
  blur while the telescope moves. They are not relabelled as completion images.
- A slew-completed event reserves one separate post-slew image, even when the
  motion burst has used its quota. Selection waits for settled timing that puts
  the estimated exposure start, minus a full-frame freshness margin, after the
  completion notification. A later delivery timestamp alone is insufficient.
- The pending completion request does not stop, cancel or restart an exposure.
  At 30–60 seconds it can wait several exposure cycles. Send spacing and consent
  remain enforced; duplicate notifications do not continually reset the wait.
- Post-slew captions explicitly say exposure timing is estimated. The SDK video
  path has no sensor exposure-start timestamp; native buffering, readout delays
  and clock changes prevent a guarantee of exact optical timing.

One pending completion is retained, not an image backlog. It expires after
four known exposure durations plus 180 seconds (minimum 300, maximum 3600), or
when the capture session/consent changes. A new slew supersedes it. Missing or
transition timing never qualifies. No new physical-camera testing is claimed.
The separate settings-window and periodic-schedule PR is not included.

## Install or upgrade

Use **AutoPierCam-0.2.24-x64.msi**. Existing settings and images are preserved.
NINA plugin **0.2.24.0** is distributed through both public plugin feeds:
`https://nina-plugins.psf-guard.com/` and `https://nina-plugins.pulsarfab.com/`.
Minimum NINA remains **3.2.0.9001**. The plugin never opens a camera handle.
