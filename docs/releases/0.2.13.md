AutoPierCam 0.2.13 adds ASI662MC Direct USB through Regain 0.5.2.

## Changes

- ASI662MC now supports the experimental Direct USB driver: 1920×1080 RGGB
  RAW16, bin 1, gain 0–600, and exposures from 32 microseconds to 2,000 seconds.
- Fix centered ROI alignment on both axes. Small ASI662MC crops no longer fail
  because their vertical origin is not aligned to 8 pixels.
- Update driver guidance, worker version checks and third-party notices.

SDK remains the default. Existing settings do not switch drivers. To use Direct
USB, select it in Settings, select the camera again, then save. RAW8 output is
derived from RAW16. Short ASI662MC direct exposures have an approximately 100 ms
minimum frame interval; the configured preview-rate cap still applies.

Upstream Windows hardware tests cover ASI662MC captures through 600 seconds,
retained-frame replay, interrupted reads and cancellation. The advertised
2,000-second limit is not yet hardware-validated on this model. Cold startup,
optical accuracy and Linux/macOS hardware remain unvalidated. AutoPierCam's
integration tests use simulated cameras and do not establish hardware behavior.

## Install or upgrade

Install **AutoPierCam-0.2.13-x64.msi** to update the agent and Viewer. Settings,
pairing and saved images are preserved. The ZWO USB driver is still required on
Windows; Direct USB does not load the ZWO camera SDK. No USB reset, automatic
backend fallback or discovery during capture is added.

NINA plugin **0.2.13.0** is published through both shared registries:

- `https://nina-plugins.psf-guard.com/`
- `https://nina-plugins.pulsarfab.com/`

Minimum NINA version remains **3.2.0.9001**. The plugin requires the separately
installed AutoPierCam agent and never owns the camera.
